# 🏡 Rongkhem Smart Village
## ระบบบริหารจัดการหมู่บ้านอัจฉริยะ บ้านร่องเข็ม หมู่ที่ 6

โครงการพัฒนาระบบสารสนเทศเพื่อการบริหารจัดการหมู่บ้าน  
บ้านร่องเข็ม หมู่ที่ 6 ตำบลจำป่าหวาย อำเภอเมือง จังหวัดพะเยา

## 🎯 วัตถุประสงค์

- จัดเก็บข้อมูลประชาชนและครัวเรือนอย่างเป็นระบบ
- สนับสนุนการบริหารงานของผู้ใหญ่บ้านและคณะกรรมการหมู่บ้าน
- พัฒนาระบบข้อมูลกลุ่มเปราะบาง ผู้สูงอายุ และสุขภาพชุมชน
- ส่งเสริมการเป็นหมู่บ้านอัจฉริยะ (Smart Village)

## 📌 ระบบภายในโครงการ

👥 ทะเบียนประชาชน  
🏠 ทะเบียนครัวเรือน  
👴 ผู้สูงอายุ  
❤️ กลุ่มเปราะบาง  
🩺 ระบบสุขภาพและ อสม.  
🛡️ ชรบ.  
🏛️ คณะกรรมการหมู่บ้าน  
🛕 ข้อมูลวัดและกิจกรรมชุมชน  
💼 วิสาหกิจชุมชน  
🏞️ แหล่งท่องเที่ยวชุมชน  
📄 หนังสือราชการและรายงาน

## 🌱 ข้อมูลการพัฒนาชุมชน

- การจัดการทรัพยากรธรรมชาติและสิ่งแวดล้อม
- การลดการเผาและแก้ไขปัญหา PM2.5
- การพัฒนาแหล่งซับน้ำจำ
- การส่งเสริมเศรษฐกิจชุมชน
